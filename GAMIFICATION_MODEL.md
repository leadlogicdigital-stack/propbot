# PropBot Gamification & Lead Rewards System

## 🎯 Core Vision

Transform real estate sales professionals from passive data providers to engaged, incentivized contributors by rewarding them with **high-quality buyer leads** based on their submission activity.

✅ **Exclusivity** - Higher tiers = better quality leads
✅ **Transparency** - Clear earning/redemption rules

### For PropBot:

✅ **Lead Monetization** - Convert lead database to rewards
✅ **Network Effects** - Attracts more active professionals

## 📋 Technical Implementation

### Database Schema

```
AGENTS_COINS:
├─ agent_id: string (unique)
├─ current_balance: number
├─ total_earned: number
├─ total_redeemed: number
├─ last_submission_date: timestamp
├─ submission_streak: number
└─ created_date: timestamp

COIN_TRANSACTIONS:
├─ transaction_id: unique
├─ agent_id: string
├─ type: "earned" | "redeemed" | "bonus" | "refund"
├─ amount: number
├─ reason: string (e.g., "Submission approved", "Milestone bonus")
├─ submission_id: string (if earned from submission)
├─ lead_package_id: string (if redeemed)
└─ timestamp: timestamp

LEADS:
├─ lead_id: unique
├─ status: "available" | "reserved" | "claimed" | "archived"
├─ quality_tier: "basic" | "targeted" | "premium" | "vip" | "elite"
├─ buyer_name: string
├─ buyer_phone: string
├─ buyer_email: string
├─ property_interest: object {
│   ├─ location: string (PIN code)
│  ├─ property_type: string
│   ├─ budget_range: {min, max}
│   ├─ timeline: string
│   └─ special_requirements: string
│ }
├─ background_data: object
├─ interest_level: "cold" | "warm" | "hot"
├─ created_date: timestamp
├─ redeemed_by: agent_id
├─ redeemed_date: timestamp
└─ conversion_date: timestamp (if converted to deal)

LEAD_PACKAGES:
├─ package_id: unique
├─ package_type: "tier_1" | "tier_2" | ... | "custom_search"
├─ coin_cost: number
├─ lead_count: number
├─ filters: object (location, type, price, etc.)
├─ quality_tier: string
└─ description: string
```
