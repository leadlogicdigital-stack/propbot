🚀 Getting Started

For Developers:

  1. Clone: git clone https://github.com/leadlogicdigital-stack/propbot.git
  2. Install dependencies: npm install
  3. Start frontend: cd frontend && npm run dev
  4. Start API: cd api && npm run dev
  5. View at http://localhost:3000
